# AgentMesh v0.3.1

本版本只调整 Studio 设置页的界面表现，不改变任何运行时行为、数据格式或命令行接口。

## 界面调整

- 「版本与更新」两张卡片的提示图标统一为同一个小尺寸 `?` 按钮，标题与开关标签共用同一实现。
- 两个自动检测开关的标签简化为「自动检测更新」，归属由卡片标题区分。
- 版本信息项标签统一为「当前版本」和「最新版本」，不再重复卡片已表达的归属。
- 安装路径这类长值单独使用更小字号，换行后仍可读。
- 桌面应用的「安装并重启」与命令行工具的操作按钮移到状态徽标右侧，标签按状态收敛为「安装」「更新」「重装」。
- 版本卡片内的内联提示改用更小字号与更紧的内边距，不再压过卡片主体信息。
- 「Agent 工具」新增批量操作入口，位于就绪计数徽标右侧：待处理项全部缺失时显示「一键安装」，包含内容不一致或无法读取时显示「一键修复」，全部正常时隐藏。批量操作只处理 CLI 已检测到的工具。
- Agent Skill 各行的操作按钮缩小到与版本卡片一致的尺寸。

## 兼容与升级

- Packet schema 保持 v2，与 v0.2.x 及 v0.3.0 工作区兼容，不需要迁移已有 run。
- 无配置迁移，无命令行接口变更。从 v0.3.0 升级可直接覆盖安装。
- CLI 与 Desktop 仍是两个独立安装渠道，各自升级。

## 已知限制

- Desktop 资产未签名、未 notarize，首次打开需要在 Finder 中右键选择「打开」，或对已安装副本执行
  `xattr -dr com.apple.quarantine /Applications/AgentMesh.app`。
