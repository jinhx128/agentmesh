# AgentMesh v0.2.1

## 修复与体验

- 修复使用第三方 Provider/API Key 添加 Codex Agent 时错误要求官方 `codex login` 的问题。
- 当 Codex 官方登录态不可用时，使用候选 Agent 的 provider、model、reasoning 和环境配置发起一次真实模型探测；第三方凭据有效即可通过注册检查。
- Codex 回退探测使用临时会话和只读 sandbox，并明确要求不访问文件、不执行命令。
- 注册诊断现在能区分无效 Key、模型不可用、网络错误、空响应和超时；Codex 默认探测超时调整为 60 秒。

## 兼容与升级

- Packet schema 保持 v2，与 v0.2.0 工作区兼容，不需要迁移已有 run。
- 第三方 Codex Provider 无需同时登录官方账号，但注册探测会发起一次最小模型请求，可能产生少量 API 用量。
- CLI 与 Desktop 是独立渠道：CLI 从 npm 或同版本 GitHub tarball 更新；Desktop 使用同版本 DMG 完整替换，或由已启用 updater 的版本执行应用内更新。
- macOS DMG 面向 Apple Silicon，当前未做 Apple Developer ID 签名或 notarization；Tauri updater archive 使用独立更新密钥签名。
