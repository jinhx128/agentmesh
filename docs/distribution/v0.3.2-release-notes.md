# AgentMesh v0.3.2

本版本修复 macOS 系统代理绕过规则的转发问题，不改变数据格式与命令行接口。

## 修复

- macOS 代理例外列表转发给 agent 子进程时会改写成各 CLI 都能识别的写法。此前 `scutil --proxy` 的
  `ExceptionsList` 被原样拼进 `NO_PROXY`，其中 `*.example.com` 这类 macOS glob 写法和 `<local>`
  这类 macOS 专有 token 在部分 agent CLI 的 HTTP 客户端中无法匹配，导致本应绕过代理的内网端点
  仍然走代理，agent 派发表现为连接反复重试直至超时。
- 现在 `*.example.com` 与 `.example.com` 统一改写为 `example.com`，`<local>` 被丢弃，`*`
  保持原样，CIDR 与裸主机名不变，折叠后去重。裸域名形式在实测的 Rust、Bun 与 Node HTTP
  客户端中都能匹配目标主机及其子域。

## 影响范围

- 只影响 macOS 且系统代理配置了例外列表的环境；其他平台与未配置例外的环境行为不变。
- 受影响的是访问例外列表内端点的 agent：修复前这些 agent 的调用会超时，修复后正常派发。
- 访问公网端点的 agent 不经过例外列表，行为不受本次修复影响。

## 兼容与升级

- Packet schema 保持 v2，与 v0.2.x、v0.3.0 及 v0.3.1 工作区兼容，不需要迁移已有 run。
- 无配置迁移，无命令行接口变更。从 v0.3.1 升级可直接覆盖安装。
- CLI 与 Desktop 仍是两个独立安装渠道，各自升级。

## 已知限制

- 代理例外列表本身仍由系统代理配置决定。若目标域名不在例外列表内，AgentMesh 会按系统设置
  将其转发给代理；需要绕过时请把域名加入 macOS 的代理例外列表。
- Desktop 资产未签名、未 notarize，首次打开需要在 Finder 中右键选择「打开」，或对已安装副本执行
  `xattr -dr com.apple.quarantine /Applications/AgentMesh.app`。
