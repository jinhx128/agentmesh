# AgentMesh v0.2.0

## 新功能与体验

- Packet schema 升级为 v2，运行状态与阶段状态显式记录，支持重复阶段节点、重试、继续运行和更准确的运行诊断。
- Direct Call 结果记录改为结果处理状态，支持主控 Agent 通过 CLI 标记或选择结果；Studio 只读展示调用证据，不代替主控做采纳决策。
- Run 与 Call 详情统一为可读的总览、关联、内容和产物布局，支持 Markdown 预览、错误输出、时间信息和关联项展示。
- Studio 活动导航统一 Runs 与 Calls，增加中文状态、分组预览、展开、删除、刷新和更清晰的列表分隔。
- 设置页整合版本与更新：分别展示 AgentMesh CLI 与桌面应用状态，支持 CLI 检测/安装/更新、桌面端原生更新和自动检查偏好；不再显示容易误导的聚合“已是最新”状态。
- AgentMesh Skill、更新诊断、调用产物和桌面 sidecar 运行时同步到当前协议与发布版本。

## 兼容与升级

- `0.2.0` 使用当前 Packet schema v2；旧 packet 不自动迁移，需要按当前 schema 重新创建 run。
- CLI 与 Desktop 仍是独立渠道：CLI 从 npm 或同版本 GitHub tarball 更新；Desktop 使用同版本 DMG 完整替换，或由已安装的 updater-enabled 版本执行应用内更新。
- 旧格式 Call 记录不自动迁移到新的结果处理模型；新调用使用 `result_status`、结果事件和比较组字段。
- macOS DMG 面向 Apple Silicon，当前仍未做 Apple Developer ID 签名或 notarization；Tauri updater archive 使用独立更新密钥签名。
