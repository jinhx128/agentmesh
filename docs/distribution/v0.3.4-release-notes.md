# AgentMesh v0.3.4

修复创建和修改 Agent 时，本机已经配置的模型未出现在可选列表中的问题。

## 修复

- 模型发现合并 CLI 查询结果与各工具的本机模型配置，并去重。
- Codex 读取 `config.toml` 的当前模型和 `model_catalog_json` 指向的自定义模型目录。
- Claude 读取设置中的模型环境变量，保留代理前缀和 `[1M]` 等原始调用值。
- Cursor 合并选中模型和模型参数中的模型；OpenCode 合并未禁用 provider 的模型配置；Antigravity 合并设置中的当前模型。
- 模型下拉使用易读名称，保存和实际调用继续使用原始模型 ID。
- 活动列表标题为删除按钮预留空间，避免文字与按钮重叠。

## 兼容与升级

- 数据格式、Packet schema 和命令行接口不变，无需迁移已有数据。
- CLI 与 Desktop 是独立安装渠道。桌面端需要安装本版本完整 DMG 或使用应用内更新，更新 CLI 不会替换桌面端内置资源。
- 发布资产包含 npm tarball、macOS Apple Silicon DMG、已签名的 Tauri 更新归档与签名、`latest.json`、Skill markdown 和 `SHA256SUMS`。
- DMG 未使用 Developer ID 签名、未 notarize，首次打开可能需要在 Finder 中右键选择「打开」。

## 使用说明

- 配置中的模型表示用户已指定该模型，不保证当前账号、代理或登录态能够成功调用；实际可用性仍由对应工具确认。
- 工具查询失败时，已读取到的本机配置模型仍可用于选择。
