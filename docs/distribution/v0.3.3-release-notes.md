# AgentMesh v0.3.3

本版本把 v0.3.2 的代理例外改写补齐到桌面端，不改变数据格式与命令行接口。

## 修复

- Desktop Studio 转发给 sidecar 的 `NO_PROXY` 现在也会改写成各 HTTP 客户端都能识别的写法。
  桌面端的 Rust 侧有一份独立的 `scutil --proxy` 解析，v0.3.2 只修了 runtime 的 TypeScript
  路径，该解析仍把 `*.example.com` 与 `<local>` 原样拼进 `NO_PROXY`。
- 受影响的是 Desktop Studio 进程内的网络请求：更新检查与从桌面端派发的 agent 在访问代理
  例外列表内的端点时会错误地走代理，表现为请求失败或反复重试。
- 改写规则与 v0.3.2 的 runtime 侧一致：`*.example.com` 与 `.example.com` 统一改写为
  `example.com`，`<local>` 被丢弃，`*` 保持原样，CIDR 与裸主机名不变，折叠后去重。

## 影响范围

- 只影响 macOS 且系统代理配置了例外列表的环境。
- 只影响 Desktop Studio。通过 `agentmesh` CLI 派发的 agent 在 v0.3.2 已经修复。
- 访问例外列表之外端点的请求行为不变。

## 兼容与升级

- Packet schema 保持 v2，与 v0.2.x 及全部 v0.3.x 工作区兼容，不需要迁移已有 run。
- 无配置迁移，无命令行接口变更。从 v0.3.2 升级可直接覆盖安装。
- 本次修复位于桌面应用内部，需要安装新的 DMG 才能生效；只更新 PATH 中的 CLI 不会改变
  已安装的 `AgentMesh.app`。

## 已知限制

- 代理例外列表本身仍由系统代理配置决定。若目标域名不在例外列表内，请求会按系统设置
  转发给代理；需要绕过时请把域名加入 macOS 的代理例外列表。
- Desktop 资产未签名、未 notarize，首次打开需要在 Finder 中右键选择「打开」，或对已安装副本执行
  `xattr -dr com.apple.quarantine /Applications/AgentMesh.app`。
