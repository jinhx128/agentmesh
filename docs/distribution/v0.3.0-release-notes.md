# AgentMesh v0.3.0

## 变更行为

- AgentMesh Skill 的安装与检测位置从项目目录改为用户主目录：`codex`、`cursor`、`antigravity`、`opencode` 写入 `~/.agents/skills/agentmesh/SKILL.md`，`claude` 写入 `~/.claude/skills/agentmesh/SKILL.md`，一次安装对所有项目生效。
- 旧版本写在 `<project>/.agents/skills/` 与 `<project>/.claude/skills/` 的项目级副本不再写入也不再校验。项目级副本会在该项目内遮蔽全局文件，版本落后时需要手动删除。
- macOS 上 `Cmd+W` 只隐藏窗口，应用保留在 Dock；退出改由 `Cmd+Q` 负责，点击 Dock 图标可重新唤出窗口。

## 新增

- 命令行工具新增独立的自动检测开关。关闭后启动不再查询 npm registry，手动刷新始终执行检查；该偏好与桌面端自动检测互不影响。
- 桌面应用或命令行工具存在可用更新时，Studio 设置入口显示红点提示。

## 修复

- 桌面端更新检查复用 macOS 系统代理。GUI 启动的进程不继承终端代理变量，updater 的 HTTP 客户端只读取自身进程环境，Node 的全局 fetch 还需要 `NODE_USE_ENV_PROXY` 在进程启动前就位；现在启动时读取一次 `scutil --proxy` 并转发给 sidecar，仅在环境未配置代理时生效。
- CLI 版本探测对带 node shebang 的脚本显式使用 Node.js 运行时，避免宿主环境缺少解释器关联时探测失败。
- 外部 CLI 卡片不再把「已找到」这类成功诊断当作告警展示。

## 界面调整

- 环境页合并进关于页，改用「版本与更新」和「Agent 工具」两个子标签；标注文案随子标签切换。
- 版本与更新改为左右分栏：桌面应用与命令行工具各占一张卡片，信息项标签与值同行。
- Agent 工具把 CLI 检测与 Skill 安装状态合并为单一列表，按状态收敛操作入口。
- 高级页移除与子标签重复的标题，用户配置路径移到保存按钮旁。
- 桌面窗口默认与最小尺寸调整为 1024×700。

## 兼容与升级

- Packet schema 保持 v2，与 v0.2.x 工作区兼容，不需要迁移已有 run。
- 升级后建议执行一次 `agentmesh skill install --target <host>`，把 Skill 写入用户主目录；随后可删除项目内的旧副本。
- CLI 与 Desktop 是独立渠道：CLI 从 npm 或同版本 GitHub tarball 更新；Desktop 使用同版本 DMG 完整替换，或由已启用 updater 的版本执行应用内更新。
- macOS DMG 面向 Apple Silicon，当前未做 Apple Developer ID 签名或 notarization；Tauri updater archive 使用独立更新密钥签名。
