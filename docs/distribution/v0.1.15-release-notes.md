# AgentMesh v0.1.15

## 修复与体验

- Studio 统一 Agent、Workflow、Preset、设置、CLI/Skill 安装、活动删除、Call 采纳、Reviewer Session 和 Run 安全操作的写操作反馈：成功使用绿色 toast，失败使用红色 toast；失败时保留弹窗、表单和当前上下文。
- Agent 编辑弹窗会主动刷新可选模型，并将模型缓存缩短为 15 秒；Codex Agent 保存前的就绪检查不再造成长时间等待。
- Codex CLI 默认携带 `--skip-git-repo-check`，允许从包含多个子仓库、但顶层本身不是 Git 仓库的工作目录调用。
- Studio 活动列表增强未选中项的边界与分隔层级，提升密集列表中的可读性。

## 兼容与升级

- CLI 命令、配置 schema、packet schema 和 workflow recipe 保持兼容，不需要迁移现有工作区数据。
- CLI 与 Desktop 仍是独立渠道：CLI 从 npm 更新；Desktop 可用本版本 DMG 完整替换，或由 updater-enabled 版本执行应用内更新。
- macOS DMG 面向 Apple Silicon，未做 Apple Developer ID 签名或 notarization；Tauri updater archive 使用独立更新密钥签名。
