# 调用产物布局设计

## 目标

调用详情沿用运行详情的双栏阅读方式：主区域展示详情和当前选中产物内容，右侧纵向展示产物列表。

## 交互

- 右侧列表固定展示提示词、输出和错误输出，不因文件缺失而隐藏条目。
- 每项以“已生成 / 无内容”说明是否存在可读内容，不再使用“已找到 / 未找到”这类文件检查文案。
- 每项右侧显示 `HH:mm:ss`：提示词使用调用创建时间，输出和错误输出使用调用结束时间；尚未结束时显示 `--:--:--`。
- 默认优先选中输出；没有输出时依次选择提示词、错误输出。
- 点击右侧条目后，主区域下方只展示该产物内容。
- `.md` / `.markdown` 产物复用运行详情的安全 React Markdown 渲染；其他扩展名继续按纯文本展示。
- 切换到另一条调用时，重新按默认优先级选择。
- 失败摘要仍显示在内容模块中，不伪装成文件产物。
- 移动端将右侧列表放到主内容上方。

## 边界

复用调用详情 API 已返回的预览和调用时间，不新增请求、不改变 Call Record 或 App Server 接口，不采用抽屉预览。

## 验收

- 不再出现横向产物流程和三份内容同时平铺。
- 右侧产物列表具有选中态，主区域只渲染选中内容。
- 无输出、无错误输出时仍保留固定条目，并明确显示“无内容”。
- 三项均显示对应时间或稳定的时间占位符。
- Markdown 标题、强调、列表、表格和代码块以格式化内容显示，纯文本不会被误解析。
- 桌面端双栏、移动端单栏均无内容溢出。

## 详情与关联 Tab

### 目标

将调用页连续排列的“详情”和“关联”卡片收敛为与运行页一致的顶部 Tab，减少首屏纵向占用，同时保持调用产物的阅读位置稳定。

### 交互与布局

- 主栏顶部展示“详情 / 关联”两个 Mantine Tab，视觉、键盘交互和焦点样式复用运行页 `run-detail-tabs`。
- 默认选中“详情”；切换到另一条调用时自动回到“详情”。
- “详情”面板只展示调用字段；“关联”面板只展示关联的运行和调用。
- 警告和当前产物内容位于 Tab 之后，始终可见，不随 Tab 切换。
- 右侧产物列表保持现有位置和选中状态，不随 Tab 切换。
- 空关联仍显示“暂无记录”，不隐藏 Tab 或面板。

### 实现边界

Tab 状态由 `CallDetailView` 内部维护，不提升到全局 `App`；不新增 API、数据字段或依赖。调用 Tab 使用独立样式类，但复用运行页已有的分段控件视觉规则。

### 验收

- 页面不再同时展示“详情”和“关联”两个独立卡片。
- Tab 默认选中“详情”，可通过鼠标和键盘切换到“关联”。
- 切换 Tab 不影响当前产物选择，内容区和右侧产物列表保持可见。
- 切换调用后 Tab 恢复为“详情”。
