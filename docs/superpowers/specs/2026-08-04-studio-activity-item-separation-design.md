# Studio 活动项分隔优化设计

## 目标

让左侧活动导航中的未选中项拥有清晰但克制的边界，避免连续记录在视觉上连成一片，同时保持当前紧凑的信息密度。

## 设计

- 未选中项使用浅灰白背景、1px 中性边框和现有圆角体系。
- 相邻活动项保持 8px 的稳定间距，边界不依赖标题长度或状态标签。
- 悬停态仅轻微加深背景和边框，不增加阴影，避免侧栏显得厚重。
- 选中项继续使用品牌色浅底，并提高边框对比度，确保层级明显高于未选中项。
- 删除按钮、运行/调用标签、状态、时间、日期分组和展开逻辑保持不变。

## 实现范围

- 仅调整 `apps/studio-web/src/styles.css` 中活动导航项相关样式。
- 不修改活动数据结构、选择逻辑、删除逻辑或 React 组件层级。
- 在 `tests-node/studio-ui.test.ts` 增加样式契约回归断言。

## 验证

- 测试先证明未选中项缺少背景、边框和状态层级契约。
- 修改样式后运行 Studio UI 定向测试。
- 运行全量测试和 `git diff --check`。
