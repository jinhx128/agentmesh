# 运行总览字段分栏设计

## 目标

将运行总览字段从自动逐行填充的两列网格改为两组明确的字段列，使同类信息集中、阅读顺序稳定。

## 字段顺序

- 左列：标题、运行、Workflow、开始时间、结束时间、耗时。
- 右列：工作区、状态、当前节点、阶段、运行目录。
- 桌面端同时展示左右两列；窄屏先完整展示左列，再完整展示右列。

## 实现方式

`RunSummaryPanel` 分别构造左右两组字段，并在 `run-summary-row` 内渲染两个语义明确的列容器。每列内部仍复用 `CompactDetailItem`，不通过 CSS `order` 或 `nth-child` 重排字段。

## 边界

- 不修改运行数据、字段值、状态计算或文案。
- 不修改 App Server、SDK、Packet schema 或其他运行详情模块。
- 保持现有字段换行、溢出处理和移动端单列适配。

## 验收

- SSR 输出中左列和右列各自具有稳定标记，并严格按约定顺序包含字段。
- 桌面端两列等宽，列内字段纵向排列。
- 窄屏两列容器改为单列布局，DOM 阅读顺序为完整左列后完整右列。
- Studio UI 定向测试、完整测试和前端构建通过。
