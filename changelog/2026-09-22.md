## 18:00 - 准备 AgentMesh 0.3.2 发布

修复 macOS 代理例外列表转发给 agent 子进程时的写法不兼容问题。

- `parseMacProxyExceptions` 新增 `normalizeProxyException`：`*.example.com` 与 `.example.com` 统一改写为 `example.com`，丢弃 `<local>` 这类 macOS 专有 token，`*` 保持原样（本身即「全部绕过」的合法写法），CIDR 与裸主机名不变，折叠后去重。
- 此前 `scutil --proxy` 的 `ExceptionsList` 被原样拼进 `NO_PROXY`。macOS glob 写法在部分 agent CLI 的 HTTP 客户端中匹配不到目标主机，本应绕过代理的内网端点仍被转发给代理，agent 调用表现为 `Reconnecting` 反复重试直至超时。
- 将 root、全部 workspace、内部 exact dependencies、Tauri/Cargo、updater 示例、运行时版本常量和版本测试同步到 `0.3.2`。
- 更新 README 当前发布入口，新增 `docs/distribution/v0.3.2-release-notes.md`；历史 changelog 与既往发行说明保持不变。

### 转换目标的选取依据

改写目标不是凭惯例选的 `.example.com`，而是实测后选的裸域名。三种写法在死代理下的对照（成功 = 绕过生效直连到达）：

| 写法 | codex (Rust) | claude (Bun) | opencode (Bun) | Node/undici |
| --- | --- | --- | --- | --- |
| `*.domain.com` | 失败 | 失败 | 失败 | 成功 |
| `.domain.com` | 失败 | 成功 | 成功 | 成功 |
| `domain.com` | 成功 | 成功 | 成功 | 成功 |

只有裸域名在全部实测栈中生效，且四个栈都能用它匹配子域。若按惯例改写为 `.example.com`，对 Rust 栈仍然无效。
