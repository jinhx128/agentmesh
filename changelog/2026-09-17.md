# 2026-09-17

## 10:30 - 准备 AgentMesh 0.3.0 发布

- Skill 安装与检测位置从项目目录改为用户主目录，一次安装覆盖所有项目；旧的项目级副本不再写入也不再校验。
- 桌面端更新检查复用 macOS 系统代理：启动时读取一次 `scutil --proxy` 写入本进程并转发给 sidecar，Node 侧补 `NODE_USE_ENV_PROXY=1`，仅在环境未配置代理时生效。
- 命令行工具新增独立自动检测开关 `auto_check_cli`，关闭后启动不查询 npm registry；偏好写入改为按字段部分更新，避免改一个开关重置另一个。
- 设置入口用 Indicator 包裹，桌面应用或 CLI 任一存在可用更新即亮红点。
- macOS `Cmd+W` 只隐藏窗口，退出改由 `Cmd+Q` 负责，Dock 点击可重新唤出。
- 环境页合并进关于页并改用子标签；版本与更新改为左右分栏；Agent 工具合并 CLI 检测与 Skill 状态；桌面窗口默认与最小尺寸调整为 1024×700。
- 将 root、全部 workspace、内部 exact dependencies、Tauri/Cargo、updater 示例、运行时版本常量和版本测试同步到 `0.3.0`。
- 更新 README 当前发布入口，新增 `docs/distribution/v0.3.0-release-notes.md`；历史 changelog 与既往发行说明保持不变。
